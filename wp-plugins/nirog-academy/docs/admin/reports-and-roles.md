# Overview

**Courses → Overview** shows active participants, new this month, items needing review, device requests, **who needs a check-in** (active 5+ days but not seen for 5 days), access ending in 14 days, and the next live sessions.

# Reports

**Courses → Reports** — per programme, how many people started and completed each lesson. A sharp drop between two lessons is worth a look. **Download participant progress (CSV)** exports name, email, phone, batch, status, dates, progress and last activity.

# Participant page

Click any participant name: enrollments, lesson-by-lesson progress, device, and an activity log.

# Staff roles

Assign roles in **Users → edit user → Role**.

| Role | Can |
| --- | --- |
| Administrator | Everything, including settings and video import. |
| Course Manager | Programmes and lessons, enrollments, payment links, devices, announcements, reports, audit log. Not WordPress settings or plugins. |
| Course Coach | See participants and progress; send announcements to their own batches. |
| Course Participant | Only their own Courses area. Never sees WordPress admin. |

Keep only one or two Administrators. Turn on two-factor login for staff (see [Security and backups](security-and-backups.md)).
