# Announcements

**Academy → Announcements**: title, message, audience (everyone, one programme, or one batch), and optionally **Also email**. Messages appear in the participant's bell. Large audiences are emailed in batches of 40 every 15 minutes. Coaches can send only to their own batches.

# Automatic messages

| When | In-app | Email |
| --- | --- | --- |
| Enrollment created | Welcome | Welcome + choose password (new accounts) |
| Lessons open (6 am) | Each lesson | One digest email per person |
| No activity for 3 days | Gentle reminder | Reminder (once per 3 days) |
| Live session tomorrow / in 15–30 min | Reminder | Reminder |
| Access ends in 7 days | Warning | Warning |
| Device changed | Notice | Notice |
| Device request declined | Notice | Notice |
| All lessons completed | Congratulations | — |

Participants control lesson, reminder and announcement emails in their Profile. Timings and on/off switches are in **Academy → Settings → Notifications**.

# WhatsApp

The official WhatsApp Business API charges per conversation, so it is not built in. Add your number in Settings to show a "Chat on WhatsApp" link, and use WhatsApp broadcast lists manually if needed.
