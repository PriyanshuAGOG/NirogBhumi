# In short

A **programme** (for example "Yoga for Diabetes") contains **modules** (for example "Week 1") that contain **lessons**. Bonus items sit in a separate Bonus library. Build everything in **Academy → Programmes**.

Tip: **Academy → Settings → Create sample programme** builds a draft example you can look at and copy.

# Create the programme

1. **Academy → Programmes → Add new**.
2. Title, and a description in the main text box.
3. **Programme settings**:
   - **Short description** (and Hindi versions, optional).
   - **Access length** — 365 days for one year.
   - **Lesson release** — all at once, self-paced day by day, or by batch. See [Batches and lesson release](batches-and-release.md).
   - **Order** — tick if participants must finish each lesson before the next opens.
   - **Colour** — one of the five elements.
4. **Health and safety acknowledgement** — participants accept this once before their first lesson. Changing the English text later asks everyone to accept the new version.
5. **Featured image** (right side) — optional cover.
6. **Publish**.

# Add modules and lessons

On the programme screen, in **Curriculum**:

1. **+ Add module** and type its name (for example "Week 1: Foundations").
2. In a module press **+ Lesson**. The lesson editor opens with the programme and module filled in.
3. Fill in the lesson:
   - **Lesson type** — Video, Audio or Reading.
   - **Video or audio** — choose from the Video Library. Optional **Hindi version**.
   - **Length (minutes)** — shown to participants.
   - **Opens on day** — 0 = from the start; 7 = one week in.
   - **Counts towards progress** — untick for optional lessons.
   - **Free preview** — lets any logged-in visitor watch it (use with YouTube previews).
   - **Summary** and **Safety note** (shown in a highlighted box above the video).
   - **Downloads for this lesson** (right side) — PDFs uploaded here are private.
4. **Publish**.
5. Back on the programme, drag lessons and modules into order and press **Save order**.

# Bonus library

Press **+ Bonus item** under Curriculum. Give it a **Bonus category** (for example Recipes, Q&A). Use **Opens on day** to release bonus items later.

# Live sessions

**Academy → Live Sessions → Add new**: programme, batch (or everyone), start time, length, join link (Zoom / Google Meet). Participants get reminders the day before and 15–30 minutes before. Afterwards, add the recording as a lesson (often a bonus item) and choose it under **Recording**.

# If this doesn't work

| Problem | Fix |
| --- | --- |
| Lesson not in the participant's list | Is it **Published**? Is the programme and module chosen? Press **Save order**. |
| Lesson shows "Opens on …" for everyone | Check **Opens on day**. |
| Participants see English titles in Hindi mode | Fill in "Title in Hindi" on the lesson. |
