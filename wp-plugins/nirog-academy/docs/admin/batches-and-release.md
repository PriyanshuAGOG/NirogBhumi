# In short

Each programme chooses how lessons open:

| Lesson release | Day 0 is… | Use for |
| --- | --- | --- |
| All lessons available immediately | — | Short courses, libraries |
| Self-paced | The day the participant joined | Yoga programme bought any day |
| Batch | The batch start date | Groups that start together with live sessions |

Every lesson has **Opens on day**. Lessons open at midnight India time on that day.

# Batches

**Academy → Batches → New batch**: programme, name (for example "January 2027"), start date, optional enrollment window, places and coach.

- With **Batch assignment: Automatic**, new buyers join the next open batch that is not full. Enrollment closes the day after the batch starts unless you set a closing date.
- People who join before the start date can log in and finish orientation; lessons open from the start date.
- If no batch is open, the enrollment is **Pending** and appears in **Needs review** until you move them into a batch.

# Changing dates

- Changing a lesson's **Opens on day** affects everyone immediately.
- Changing a batch's start date shifts all its lessons.
- Access end dates are not changed by batch edits; use **Extend** if needed.
